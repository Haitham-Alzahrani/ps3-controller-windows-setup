# Security & system changes

This document states **exactly what the installer changes on your PC**, why, and
how to undo it. Run `Setup-PS3-Controller.cmd /check` first for a read-only report
that changes nothing.

## What it changes (full setup)

| Change | Why | Reverted by `/uninstall`? |
|---|---|---|
| Installs a USB driver for the DualShock 3 (`VID_054C&PID_0268`) via `pnputil` | Lets the pairing tool / helper talk to the controller over USB | Yes |
| Adds a **self-signed certificate** to **Trusted Root CA** and **Trusted Publisher** (LocalMachine) | So the self-signed USB driver package validates and installs **without disabling Windows driver-signature enforcement** | **Yes** — removed from both stores on uninstall |
| Builds and installs `PS3LinkHelper.exe`, started at sign-in | Maintains the wireless link on the dongle route | Yes (startup entry + exe) |
| Downloads & installs DsHidMini / BthPS3 / ViGEmBus from their **official** release pages (hash-verified) | Driver stack for the controller and wireless | Yes (DsHidMini/BthPS3 removed on the dongle route; ViGEm removed) |
| On known-faulty radios, adds a scheduled task that resets the Bluetooth radio **only if Windows reports it failed** | Works around radios that drop on wake | Yes (task unregistered) |

Driver-signature enforcement is **never disabled.** No test-signing mode.

## The certificate — important for a public release

The USB driver is **self-signed** with a libwdi/Zadig-style certificate
(`...(libwdi autogenerated)`), added to the Trusted Root store so Windows accepts it.

- On a single user's machine this is a reasonable, narrowly-scoped trust decision,
  and `/uninstall` removes the cert.
- **Open design decision for wide distribution:** the certificate is currently
  **pre-signed and bundled**, so every user receives the *same* certificate in
  their Trusted Root store. The safer pattern — used by Zadig itself — is to
  **generate the certificate on each machine at install time**, so no shared
  private key is ever distributed. Recommended before broad public release.
  (Risk if kept as-is: were the signing key compromised, code signed with it would
  be trusted for code-signing on all installed machines. It is not a TLS/MITM
  exposure.)

## Reverting everything

```
Setup-PS3-Controller.cmd /uninstall
```

This removes the driver, the certificate (both stores), the helper and its startup
entry, the radio-reset task, and ViGEm. If anything is left, Device Manager →
uninstall the device with "delete driver software" is the manual fallback.

Please open a private report via the repository's security advisories (or the
